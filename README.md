# Booking Manager

Gestionale WordPress per B&B, affittacamere, case vacanza, appartamenti, residence, guest house e hotel: camere e tipologie, tariffe, disponibilità, prenotazioni, pagamenti, check-in e housekeeping.

Quarto prodotto della famiglia di Night Manager, Beach Manager e Restaurant Manager, con lo stesso server licenze. Funziona da solo: non richiede e non tocca gli altri plugin.

Lo sviluppo è in corso: la documentazione completa arriva con la prima versione.
